# Hotel_List_Page-NamlaTech-

The Hotel List Page is a responsive Single Page Application developed to manage hotel information through a simple and user-friendly interface. The application supports adding, viewing, editing, and deleting hotel records along with image uploads. Users can search hotels by title, filter them based on price range, navigate through paginated results, and view complete hotel details with location information and map integration.

The frontend is developed using ReactJS and Redux, while the backend uses Node.js and Express.js. PostgreSQL is used as the database, with native SQL queries for storing and managing hotel data. The application follows a reusable component-based structure and provides form validation, responsive design, and basic error handling.
